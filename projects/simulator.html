Two‑Phase Microflow Simulator

Why I Built It

Phase‑field simulation software is powerful, but it’s hard to get your hands on. The leading tools are expensive or require an institutional license, and the free ones usually assume programming experience, so the learning curve is steep. I wanted a lightweight way to show the core idea of my research, that geometry and wettability can steer droplets, to people who don’t run CFD for a living.

How It Works

Users set up a 2D microchannel in the browser: geometry and mesh, inlets and outlets, fluid properties (water and cyclohexane by default), and wall wettability, including a contact angle that can vary along each wall, which is the same idea as my dissertation’s gradient channels. Then they watch the interface, velocity, and pressure fields evolve in real time.

Under the hood, it couples the Cahn–Hilliard phase‑field equation with incompressible Navier–Stokes, using the same formulation as COMSOL’s two‑phase phase‑field interface so the results can be compared directly. Field data can be exported as CSV.

I validated it against standard benchmark cases: pressure‑driven channel flow, the pressure jump across a static droplet, and droplets resting on surfaces at set contact angles. All matched theory closely.

What I learned

This project became a case of learning by building. To get the simulator right, I had to understand the Cahn–Hilliard and Navier–Stokes equations far more deeply than any software manual had taught me: how the interface forms, how the two fluids are coupled, and how each term shapes the flow. I came away with a much clearer picture of the physics behind my own research.

It also pulled me into new territory. Working on a website meant learning to read and edit HTML, CSS, and JavaScript, which I’m still building on. Most of all, it reinforced a habit I bring to every model: understand the physics fully, then check every result against something you know is true
