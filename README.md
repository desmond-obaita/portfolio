# Desmond Obaita — Portfolio

Plain HTML/CSS/JS. No build step, so GitHub Pages serves it as is.

## Publish on GitHub Pages
1. Create a repo named `YOUR-GITHUB-USERNAME.github.io` (this gives you the clean URL `https://YOUR-GITHUB-USERNAME.github.io`).
   Any other repo name works too; the site will live at `https://YOUR-GITHUB-USERNAME.github.io/REPO-NAME/`.
2. Upload everything in this folder (keep the folder structure) to the repo's `main` branch.
3. In the repo: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / root**.
4. Wait a minute, then open the URL.

## Before you go live, search for `EDIT:` and fix
- `YOUR-GITHUB-USERNAME` → your GitHub username (simulator links, in `index.html` and `projects/simulator.html`)
- `YOUR-LINKEDIN` → your LinkedIn profile URL
- `assets/img/headshot.jpg` → add your photo and swap the placeholder div in `index.html`
- `assets/Desmond_Obaita_Resume.pdf` → add a general (not company-specific) résumé PDF, without your phone number
- `projects/simulator.html` → describe what the simulator actually does

## Files
- `index.html` — home page (who I am, what I do, projects, strengths, journey, direction, contact)
- `projects/*.html` — one case study per project
- `assets/css/style.css` — all styling
- `assets/js/site.js` — mobile menu and the animated hero
